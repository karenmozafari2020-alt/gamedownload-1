KAREN DOWNLOAD - RENDER

1) فایل RA-GRAPHICS.zip خودت را داخل پوشه files قرار بده.
2) پروژه را به GitHub آپلود کن.
3) در Render یک Web Service بساز.
4) Build Command:
   npm install
5) Start Command:
   npm start

بعد از Deploy، آدرس Render را باز کن.
با دکمه «دانلود فایل»، فایل واقعی از سرور دانلود می‌شود.

نکته: فایل نمونه داخل این ZIP فقط یک فایل خالی placeholder است.
